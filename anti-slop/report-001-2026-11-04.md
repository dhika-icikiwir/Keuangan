Uji keadaan error:

```
Data rusak di penyimpanan -> layar "Catatan tidak bisa dibuka", tombol Catat tidak tampil, data lama tidak tertimpa
"Coba buka lagi" setelah data diperbaiki -> catatan termuat
Penyimpanan dibuat gagal -> peringatan "Perubahan terakhir belum tersimpan di HP." tampil
"Simpan ulang" setelah penyimpanan normal -> peringatan hilang, transaksi tersimpan
```

Batasan yang belum teruji:
- Belum dicoba di HP Android sungguhan. Uji di atas memakai versi web dari kode yang sama.
- `Alert` (konfirmasi hapus, peringatan jumlah kosong) tidak berfungsi di versi web, jadi alur hapus dan pesan "Jumlah masih kosong" hanya dicek dari kode. Form memang tetap terbuka saat jumlah kosong.
- Pembaca layar TalkBack dan posisi keyboard di atas input belum dicoba di perangkat; yang dicek hanya atribut aksesibilitas di versi web.
- `npx tsc --noEmit` dan `npx expo export --platform android` lolos.
